\section{Executive Status}

\begin{statusbox}{Current conclusion}
The reproducible vGPU task demonstration is complete. Isaac Sim executes the wall,
stud, drywall board, pneumatic nail-gun proxy, collision geometry, and six fastening
events for 600 frames. The official G2 USD is loaded natively as a 46-DOF articulation
in Isaac Sim 5.1 on the vGPU 3090; the scripted root trajectory walks it to the board,
the arms enter a working pose, and the tool visits fastening points 0 through 5.
\end{statusbox}

The current MP4 is encoded from the native RTX/Replicator RGB frame sequence rendered
on the vGPU. The USD deliverable contains \texttt{/World/RenderCamera} and the official
G2 visual, collision and sensor payload references.

\section{Known Limitations}

\begin{enumerate}[leftmargin=2em]
  \item The current Windows + Isaac Sim 4.5 + RTX 3070 combination reports an RTX
        TLAS budget overflow and can access-violate while initializing the official
        high-resolution G2 visual/PhysX payload.
  \item Docker Desktop reaches the Genie Sim launch path but lacks a usable Vulkan
        NVIDIA library in the current container configuration.
  \item The current G2 demo records \texttt{ros2\_runtime=false}; ROS 2 package setup
        is present, but the live G2 bridge is deferred to the compatible environment.
  \item Nail penetration and board deformation are represented by a deterministic
        event model, not FEM or a validated material-fracture model.
\end{enumerate}
