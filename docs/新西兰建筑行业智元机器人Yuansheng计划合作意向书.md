尊敬的智元机器人 "Yuansheng" 计划项目组:

我方谨此表达申请成为智元机器人 "Yuansheng" Deployment State Partner 的合作意向,拟以 **Task Deployment Mode** 为部署模式,围绕新西兰建筑行业相关工序及奥克兰交通局(Auckland Transport, AT)相关基建/站点场景,推动智元机器人产品在新西兰市场的落地部署。

### 二、拟申报场景

**首发场景**:新西兰建筑行业内墙板/石膏板(GIB®)装订,属 Task Deployment Mode 下的任务导向型应用。

**规划扩展场景**:建筑框架搭建、浴室防水工程、瓷砖铺贴、封顶与屋面防水、外水(给排水/管线)工程、地基浇筑,按技术复用度与安全风险由近及远分阶段申报。

**拓展场景**:奥克兰交通局(AT)相关基建与站点场景(车站/换乘枢纽内隔墙装订、设施巡检等)——目前已与 AT 建立初步接触,作为拟推进目标。

### 三、技术准备情况

申请方团队已在 Isaac Sim 环境中,基于智元 Genie G2 机器人平台,完成人形机器人石膏板搬运与连续装订的可复现闭环仿真验证,覆盖板材抓取、搬运、贴墙定位,以及按左/中/右三列完成六个固定点的装订全流程,并记录了完整的接触力、工具压力与阶段状态数据。相关仿真录像截图、轨迹数据和运行参数记录可作为立项材料附件提供。

### 四、合作诉求

1. 请将本申请纳入 "Yuansheng" 计划立项评审(MS1)流程;
2. 请提供《Project-Approval Form》及相关配套申报模板(POC Acceptance Form、NRE Scoring Form、Cooperation Agreement),以便按官方格式补充完整申报材料;
3. 请安排后续技术对接窗口,便于双方就场景难度系数认定、机器人平台配置等事项进一步沟通。

我方期待与智元机器人建立长期合作关系,共同推动智元机器人在新西兰建筑行业及交通基础设施领域的产业化落地。

如有任何问题,欢迎随时联系。
